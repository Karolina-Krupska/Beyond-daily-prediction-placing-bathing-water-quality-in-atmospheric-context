# Step 4 - Daily environmental conditions

This folder contains the full original analysis archive in 7 numbered parts.

## Restore the analysis on your computer

1. On the repository's main page, choose **Code > Download ZIP** and extract it, or download every file from this step into the same local folder.
2. In Python IDLE, open `restore_Step4.py` from that folder and press **F5**. Choose a destination for the reconstructed ZIP. Only the Python standard library is needed.
3. The script checks the size and SHA-256 checksum of the parts and the reconstructed archive. Extract the complete ZIP and follow the analysis README inside.

Keep `restore_Step4.py` and `manifest_Step4.json` beside the `step4-*.bin` files. If you already have this step in its own extracted `Step4_GitHub` folder with the earlier `restore_zip.py` and `manifest.json`, that pair still works in its original folder.
