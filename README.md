# Step 5 - Daily bathing water exceedance predictions

This folder contains the full original analysis archive in 17 numbered parts.

## Restore the analysis on your computer

1. On the repository's main page, choose **Code > Download ZIP** and extract it, or download every file from this step into the same local folder.
2. In Python IDLE, open `restore_zip.py` from that folder and press **F5**. Choose a destination for the reconstructed ZIP. Only the Python standard library is needed.
3. The script checks the size and SHA-256 checksum of the parts and the reconstructed archive. Extract the complete ZIP and follow the analysis README inside.
